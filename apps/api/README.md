# API application

NestJS API with infrastructure and local authentication routes:

- `GET /api/v1/health`
- `GET /api/v1/ready`
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/logout`
- `GET /api/v1/auth/me`

Product controllers and future feature modules remain intentionally unimplemented. See the root API contract and module-boundary documents before adding a feature.
